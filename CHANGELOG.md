# Changelog

All notable changes are documented here. Versioning follows [Semantic Versioning](https://semver.org/). Dates are in YYYY-MM-DD format.

## [1.2.0] — 2026-09-28

### Added

- Purpose-built 1280 × 640 Social Preview image for repository owners to upload from GitHub Settings (not automatically applied to repository settings)
- Full six-stage worked demonstration using clearly simulated founder responses and illustrative financial inputs alongside three real, dated Portland public-sector/competitor sources
- Catalog-ready, transparent distribution checklist and listing copy (no third-party sites submitted or claimed)
- Community support guide with recommended Discussions categories and an editable welcome post; Discussions still require the repository owner to enable them
- Maintainer verification guide and automated JPEG size/dimension checks

### Changed

- More discoverable, keyword-natural README introduction and navigation to the showcase, community information, preview artwork and distribution kit
- Clarified separation between documented installation procedures, validated bundle structure and real end-to-end host testing

### Compatibility

- **Documentation, distribution and visual update only.** Six-stage analytical behavior and paid-tool requirements are unchanged
- Existing v1.1.0 release remains available for rollback. No external directories or communities have been posted to automatically

## [1.1.0] — 2026-09-28

### Added

- Dedicated, officially sourced installation guide for ChatGPT, Codex, Claude Code, Claude.ai, Gemini CLI, Cursor, GitHub Copilot, OpenCode, universal CLI and manual installation
- Centered language selector linking eight useful READMEs: English plus Russian, Simplified Chinese, Spanish, German, French, Brazilian Portuguese and Japanese
- Clear quick-start guide, FAQ, troubleshooting, prerequisite, privacy, manual update and rollback instructions
- A fully labeled fictional final-report example and translation-specific GitHub issue template
- `agents/openai.yaml` UI metadata that explicitly associates an optional small SVG icon and existing PNG icon with OpenAI hosts that support this metadata
- Release ZIP now includes `agents/openai.yaml` and `assets/icon-small.svg`

### Changed

- Reworked canonical README with quick-install table, platform-specific activation examples, compatibility caveats, documentation navigation and improved onboarding
- Expanded maintainer validator to check localized links, metadata icons and version consistency before a new release
- Clarified that official host integration is documented, but end-to-end operation in every agent/client/account configuration is not guaranteed

### Compatibility

- No changes to the original six-stage research workflow; this is a backward-compatible documentation, packaging and discovery enhancement
- This release does not add Claude Marketplace or ChatGPT Plugin Directory registration, any paid API access or a proprietary cross-host installer

## [1.0.0] — 2026-09-28

### Added

- Initial English-language public release of the one-off business idea stress-test workflow
- Founder interview, falsifiable idea validation, market/customer/competitor research, financial/operational assessment, adversarial review, and final decision brief
- Evidence classification to distinguish verified facts, sourced estimates, calculations, hypotheses, and unknowns
- Stage-specific English reference documents and full attribution to the seven upstream inspirations
- Generated project icon, GitHub documentation, an example session, maintainer validation, packaging, and versioned release automation

### Notes

- This is a new, independently written integration inspired by community methodologies, not a fork or bundled distribution of the original projects
- Financial scenarios are conditional illustrations, not outcome probabilities
