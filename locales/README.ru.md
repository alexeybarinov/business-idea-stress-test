# Business Idea Stress Test

**Не влюбляйтесь в бизнес-идею, пока не проверили её на прочность**

## Для чего нужен этот навык

Вместо того чтобы автоматически одобрять задумку и писать оптимистичный бизнес-план, ИИ задаёт неудобные вопросы, проверяет ключевые предположения, исследует рынок и конкурентов (при наличии доступа к актуальным источникам), рассчитывает экономику и строит сильнейшие возражения против запуска

Он нужен предпринимателям, которые хотят понять **какие доказательства уже есть, что неизвестно и какой недорогой эксперимент следует провести до крупных инвестиций**

## Как это работает

1. **Интервью:** последовательно выясняет проблему, платящего клиента, географию, бюджет, ресурсы и ограничения. Задаёт обычно один важный вопрос за раз
2. **Проверка идеи:** формулирует ключевую гипотезу, реальные альтернативы и потенциально критические препятствия
3. **Исследование:** изучает аудиторию, спрос, конкурентов и цены с учётом страны и доступных инструментов
4. **Финансовая проверка:** показывает исходные данные, расходы, маржинальность, денежные разрывы и несколько условных сценариев, а не гарантированный прогноз
5. **Жёсткая критика:** проверяет слабые источники, доводы покупателей и конкурентов, финансовые и операционные риски
6. **Вывод и тест:** формулирует условия решения, бюджет проверки, измеримые критерии успеха и причины остановить эксперимент

Навык не проводит настоящие интервью с клиентами без разрешения и инструментов, не запускает несколько независимых ИИ и не обещает успешности бизнеса. Неподтверждённые сведения отмечаются отдельно

## Как установить

**ChatGPT:** скачайте [ZIP последней версии](https://github.com/alexeybarinov/business-idea-stress-test/releases/latest), затем в поддерживаемом аккаунте откройте **Плагины → Навыки → Создать → Загрузить с компьютера**. Нужен именно прикреплённый к релизу архив навыка, а не стандартный архив исходников GitHub. Доступность функции зависит от аккаунта и рабочего пространства

**Codex:**

```bash
npx skills add alexeybarinov/business-idea-stress-test -g -a codex
```

**Claude Code:**

```bash
npx skills add alexeybarinov/business-idea-stress-test -g -a claude-code
```

**Gemini CLI:**

```bash
gemini skills install https://github.com/alexeybarinov/business-idea-stress-test.git
```

Для Cursor, Copilot, OpenCode, Claude.ai и ручной установки см. [подробную инструкцию по всем платформам](../docs/installation.md). Флаг `-g` означает установку для всех ваших проектов. Для `npx` нужны Node.js и npm; для использования самого навыка Node.js не требуется

## Как пользоваться

Создайте новый чат для каждой самостоятельной идеи. Укажите название навыка и отправьте сообщение:

```text
Используй Business Idea Stress Test. Моя бизнес-идея: [описание].
Начни с интервью и задавай по одному важному вопросу.
Мне нужна критика и проверяемые факты, а не поддержка любой ценой.
Если данных недостаточно, скажи, что нужно проверить
```

Можно прямо отвечать "не знаю". При наличии документов, интервью с клиентами или ссылок на конкурентов передайте их ИИ и укажите, к какому рынку они относятся. В конце потребуйте показать наиболее важные утверждения и их источники

**Важно:** доступ к веб-поиску и файлам определяется платформой, а не самим навыком. Не вводите пароли и чужие конфиденциальные сведения. Для дорогостоящих или юридически значимых решений может потребоваться специалист
