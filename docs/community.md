# Community and support

[← Back to README](../README.md) · [Contributing](../CONTRIBUTING.md) · [Security](../SECURITY.md)

## Where to post what

- **Bug or misleading claim:** Open a [bug report](https://github.com/alexeybarinov/business-idea-stress-test/issues/new/choose). Include the skill version, host, reproducible prompt and *sanitized* behavior, plus any unsupported claim or broken reference
- **Feature or new analysis module:** Open a [feature request](https://github.com/alexeybarinov/business-idea-stress-test/issues/new/choose). Explain which existing stage is insufficient and what observable output should improve
- **Translation problem:** Use the included translation issue template. Point to the exact file and give a corrected native-language expression
- **Open-ended question, use-case or community demonstration:** Use [GitHub Discussions](https://github.com/alexeybarinov/business-idea-stress-test/discussions) **after the repository owner enables it**. The link may not work until then
- **Sensitive security concern:** Follow the private reporting guidance in [SECURITY.md](../SECURITY.md); never post secrets or customer records in public issues or discussions

## Suggested GitHub Discussions categories

After enabling Discussions in the repository's **Settings → General → Features**, the maintainer can create these categories manually:

| Category | Use |
|---|---|
| **Q&A** | Installation questions, host-specific behavior and accepted answers |
| **Ideas & Feedback** | New checks, better interview questions and missing risk categories |
| **Show & Tell** | Sanitized example ideas, anonymized experiments and lessons learned |
| **Announcements** | Version releases, compatibility changes and known limitations |

Users should not post confidential plans, customer details, business financials, credentials or full private AI chat histories. Only post details they have rights to share

## Suggested first Discussion: Welcome

**Title:** Welcome! What would make Business Idea Stress Test more useful?

**Body:**

> Welcome to Business Idea Stress Test, an open-source workflow for examining business ideas *before* committing serious time or capital
>
> Start with the [installation guide](https://github.com/alexeybarinov/business-idea-stress-test/blob/main/docs/installation.md) and the [worked example](https://github.com/alexeybarinov/business-idea-stress-test/blob/main/docs/showcase.md). If you're reporting a bug or a specific reproducible documentation problem, please use [Issues](https://github.com/alexeybarinov/business-idea-stress-test/issues) instead
>
> We'd particularly value:
> - Which host you're using (ChatGPT, Codex, Claude, Gemini, Cursor or other)
> - Which stage helped you identify an assumption or blocker
> - What was unclear or difficult to verify
> - Whether installation or first invocation caused problems
>
> **Please share only sanitized examples.** Never publish confidential business plans, private customer data or API keys here. This project is not endorsed by the authors of the seven projects it credits

Enabling Discussions and posting a welcome message are **separate manual GitHub account actions**. Merely adding this file does not turn on Discussions
