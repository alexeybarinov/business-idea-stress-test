# Inspiration, acknowledgments, and scope

This package contains **newly authored instructions** for a unified ChatGPT-oriented workflow. It is **not an official fork, endorsement, bundled collection, or verbatim reproduction** of any project below. Their original skill files, scripts, tool dependencies, and premium APIs are **not included** and **are not executed automatically**.

## What this project does *not* do

No original upstream code has been copied into this package. Original CLI commands, Claude-specific integrations, platform-specific directories, paid services such as Firecrawl or DataForSEO, and upstream tool execution are intentionally **not required**. Research quality depends on the host application's *actual* tools and the evidence available.

It cannot independently interview buyers without human involvement, create independent multi-model consensus within one model, access subscription databases without permission, or replace professional legal/accounting advice.
